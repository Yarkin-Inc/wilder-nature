# WilderNature для Minecraft 26.3 / Fabric

Порт исходников [WilderNature](https://github.com/Let-s-Do-Collection/WilderNature), ветка `1.21.1`, commit `873285414274c044c12c5042b21e8fececa419c1`, версия 1.1.8. Версия порта — `1.1.8-port.2+mc26.3`.

## Установка и сборка

Требуются Minecraft Java 26.3, Java 25 и Fabric Loader 0.19.5 или новее. Для воспроизводимой сборки используется Gradle Wrapper 9.6 и Fabric Loom 1.17.21.

```sh
./gradlew build installationBundle
```

JAR мода: `build/libs/letsdo-wildernature-fabric-1.1.8-port.2+mc26.3.jar`.
Полный набор обязательных модов для локальной установки: `build/installation/mods/`. Его содержимое нужно положить в папку `mods` игрового профиля с Fabric 26.3.

Зависимости:

- Fabric API `0.164.0+26.3`;
- Architectury API `22.0.5`;
- Cloth Config `26.3.159`;
- Foundation WilderNature API `1.0.13-wildernature.1+mc26.3` из соседнего проекта `../letsdo-foundation`.

Foundation подключается через Gradle composite build. Это согласованный ограниченный порт API для WilderNature, а не полная библиотека для остальных модов Let's Do. Mod Menu необязателен и не включается в набор.

## Что перенесено

- Все 18 видов существ, их ИИ, атрибуты, детские варианты, сохранения и снаряды.
- Модели и анимации на извлечение состояния и отложенный рендеринг 26.3; предметы животных, плащ, шляпа, блоки, частицы и подсветка трофея.
- Реестры блоков и предметов, компоненты экипировки, топлива и еды, сохранение инвентарей блоков и мировых данных.
- Справочник и доска заданий, передача меню и типизированные сетевые пакеты для действий и синхронизации прогресса.
- Рецепты, модели предметов, таблицы добычи и генерация мира в форматах 26.3.

Бонус трюфельной еды применяется к компоненту конкретного предмета один раз при изготовлении. Он не изменяет обычную еду и не накапливается при повторном использовании. Генерация термитника сохраняет доступное хранилище и не заменяет его столб декором грунта.

В исходных анимациях белки исправлено имя базовой кости. Удалены каналы `booty` термита и `leftEar`/`rightEar` лисы: соответствующих костей в исходных моделях нет, старый движок пропускал их, а новый отклоняет всю анимацию.

## Исправления port.2

- Казуар: восстановлена привязка анимации `root` к корневой кости геометрии, как в оригинальной модели. До исправления трансформации на внешнем корне не сбрасывались и накапливались каждый кадр, уводя модель от сущности. Клиентский регрессионный тест воспроизводил это уже на анимации покоя.
- Львы: предупреждение больше не запускается заново, если уже выбрана цель боя. `LionWarnGoal` обновляется каждый тик, чтобы не пропустить последний тик предупреждения и переход к атаке.
- Сравнение `LionEntity` и `LionGoals` с исходным commit выше: до этих исправлений условия предупреждения, приоритеты целей, радиусы, урон, таймеры, защита детёнышей, помощь прайда и ночная охота были сохранены; различия касались API Minecraft. Условие повторного предупреждения при существующей цели присутствует и в оригинальном исходнике. Исправление этого зацикливания — намеренное отличие порта.

При обновлении замените JAR WilderNature `port.1` на `port.2`; зависимости остались прежними. В `build/installation/mods/` находится обновлённый набор.

## Проверка

```sh
./gradlew runGameTest
SDL_VIDEODRIVER=offscreen ALSOFT_DRIVERS=null ./gradlew runClientGameTest
```

Серверные тесты проверяют:

- создание всех 18 существ, работу ИИ, сохранение UUID, возраста и переносимых предметов;
- завершение предупреждения при существующей цели и реальные атаки взрослого льва и львицы на игрока в выживании;
- сохранение инвентарей и типов блоковых сущностей;
- генерацию заданий, сохранение прогресса, статусов наград и отменённых контрактов;
- независимость бонуса трюфельной еды, загрузку рецепта и изготовление;
- выстрел из мушкета, расход боеприпаса, износ, задержку и дробовые снаряды;
- размещение куста и термитника с корректным хранилищем и декором почвы.

Клиентский тест также проверяет отсутствие накопления трансформаций взрослого и детского казуара при 1000 повторных кадрах каждого состояния: покой, ходьба, тревога, угроза и атака (у детёныша используются доступные ему анимации). Затем открывает мир, отображает взрослые и детские модели и все предметы, открывает справочник и доску через сервер, принимает и отменяет задание по сети. Дополнительно проверяет блоки, частицы, подсветку, шляпу и плащ. Снимки сохраняются в `build/run/clientGameTest/screenshots/`.

Проверено 26 октября 2026: все 9 серверных проверок (8 тестов мода и проверка Fabric) и клиентский прогон прошли. Итоговые логи — `build/reports/porting/server-gametest.log` и `client-gametest.log`. Снимки моделей, интерфейсов, блоков и экипировки просмотрены вручную.

Тесты используют отдельные временные миры. Длительная игра, сторонние сборки и перенос миров с 1.21.1 этими проверками не покрываются.

## Границы порта

Accessories и Trinkets сохранены в исходниках, но исключены из сборки. Плащ и шляпа работают в обычных слотах экипировки. NeoForge не входит в этот порт. Оригинальные файлы NeoForge и мультиплатформенных сборок оставлены для справки; сборка 26.3 управляется корневым `build.gradle`.
